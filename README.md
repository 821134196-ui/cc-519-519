# 灯箱运营台

广告灯箱点位、亮灯计划、巡检照片、维修派单与补播核算的一体化运营台。
零第三方依赖：Python 3.10+ 标准库（`http.server` + `sqlite3`）+ 原生前端。

## 一条命令启动

```bash
./run.sh            # 首次自动建库并预置样例（含“半亮样例”）
# 或：python3 -m lightbox.serve --reseed --port 8000
```

打开 http://127.0.0.1:8000 ，预置巡查员：**张巡 / 李巡 / 王巡**。

重置样例：`./run.sh --reseed`

## 预置样例（以本周一为锚点回放）

| 灯箱 | 情形 | 处置 |
|---|---|---|
| LB-A01 | 两条灯带熄灭（**半亮样例**） | 部分灯带不亮，未关闭 |
| LB-A02 / LB-A03 | 同回路 20:00 齐黑 | **供电中断归并为一张回路故障**，一张进行中维修单 |
| LB-B01 | 计划时段内不亮、邻箱正常 | 定时器配置错 → 维修 → 复验 → 补播 100 分钟已批准 |
| LB-B03 | 首次维修后复验仍黑 | **维修后再次熄灭**，退回维修，可再派单 |
| LB-C01 | 合同空档、画面已撤 | 画面已撤换，不派修、不计补播 |
| 白天 LB-A01 巡检 | 计划时段外不亮 | **白天误判**，不立故障 |

LB-A03 上挂了青禾教育新旧两个合同版本，可演示补播按合同版本切片。

## 业务规则

- **时段判断**：周历计划支持跨午夜（如 18:00–02:00）；白天/计划时段外的不亮判为
  “白天误判”，黑屏与补播只统计计划亮灯时段。
- **故障分类**：白天误判 / 定时器配置错 / 部分灯带不亮 / 供电中断 / 画面已撤换 /
  维修后再次熄灭，六类区分处理。
- **归并**：同回路多灯箱在计划时段齐黑 → 一张供电中断回路主单，受影响广告主全部挂入；
  已归并的灯箱不再平行建工单。
- **派单唯一性**：同一故障存在未关闭维修单时，禁止创建第二张；复验不通过退回维修后可再派。
- **复验权限**：复验人不得是该故障的最初上报巡查员；不通过即记“维修后再次熄灭”。
- **补播核算**：故障窗口按黑屏发生时有效的**合同版本**切片，仅计计划分钟；
  部分灯带按实测缺额比例折算；画面撤换空档不计；补播结论**提出人不能审批**。

## 界面

- **点位地图 / 列表**：均显示灯箱编号与最近亮灯证据（最近一次满亮照片）、文字状态结论。
- **故障详情**：左列计划亮灯时段、右列实际黑屏/缺额分钟逐段对照；含巡检照片、
  派单/完工、复验、补播审批操作。
- **巡检 / 信号台**：读取模拟适配器信号拍照；可录制任意亮度/灯带数的故障信号或恢复计划信号。
- 配色为白 / 墨灰 + 广告画面预览色，所有状态同时给出文字结论，不单靠颜色区分。

## 架构

```
lightbox/
  times.py    时段纯逻辑（周历、跨午夜、区间交集，可测、无当前时钟依赖）
  db.py       SQLite schema 与连接
  signals.py  亮灯信号适配器（模拟实现，可按时刻回放/录制）
  photos.py   巡检照片本地落盘（SVG，矢量示意）
  faults.py   判障/归并/派单/复验/补播领域服务
  app.py      HTTP + JSON API
  seed.py     样例数据
  serve.py    启动入口
static/       前端（index.html / styles.css / app.js）
tests/        unittest：时段判断、故障归并、补播计算、复验/审批权限
data/         运行期生成：lightbox.db、photos/（已 gitignore）
```
