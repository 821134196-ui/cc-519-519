# 灯箱广告亮灯监管系统

广告运营方对灯箱点位、供电回路、亮灯时段与当前画面合同进行登记；巡查员在规定
时间拍照记录亮灯情况；故障单关联受影响广告主与预计恢复时间。系统区分白天误判、
定时器配置错、部分灯带不亮、供电中断、画面已撤换、维修后再次熄灭六类情形，并
按合同版本核算故障期间补播、强制复验与审批职责分离。

## 一条命令启动（预置半亮样例）

```bash
python3 -m lightbox.run --reset        # http://127.0.0.1:8000
```

不带 `--reset` 保留既有数据；`--port 8080` 换端口。演示时钟固定在
**2026-10-01 20:00（+08:00，计划亮灯时段内）**。

## 预置样例（8 个点位）

| 灯箱 | 情形 | 处理区分 |
|---|---|---|
| B001 | 全亮 | 正常，无故障 |
| B002 | **半亮**（8 条灯带 4 条亮） | partial；黑屏跨越合同换版，补播分版本核算 |
| B003 / B004 | 同回路 C2 供电中断 | 归并为同一张故障单，按箱各计黑屏与补播 |
| B005 | 计划内不亮 | 定时器配置错（timer） |
| B006 | 9-29 修复、9-30 再次熄灭 | relapse，重开原维修单、累计多轮黑屏 |
| B007 | 灯亮但登记合同已到期 | 画面已撤换（creative），不开亮灯故障/维修单 |
| B008 | 12:00 巡检时熄灭 | 白天误判（daytime），符合计划，非故障 |

## 核心业务规则

- **时段判断**：计划 18:00–23:00（支持跨午夜、星期、版本区间）；计划外熄灭
  正常，计划外仍亮判定时器错。补播只计黑屏与计划亮灯时段的重叠部分，白天不计。
- **故障归并**：同回路中断的多点位归并到一张故障单；同灯箱重复巡查只追加证据、
  不平行建单；修复后复验仍异常判 `relapse` 并重开原单。
- **禁止平行维修单**：数据库部分唯一索引保证同一灯箱同时只有一张未关闭工单。
- **补播核算**：应补播 = 时段内黑屏分钟 × 缺光比例（全黑 1.0、半亮 0.5），
  跨越合同换版时按当时生效版本分别归属广告主并乘该版本补播系数；进行中的故障
  随时间继续累计。
- **职责分离**：维修人不能复验自己的工单（须其他巡查员、且在亮灯时段内复验）；
  补播结论由巡查员提交，**提交人不能批准自己的结论**，可由其他巡查员或主管审批。

## 界面

- **点位地图 / 列表**：SVG 地图与列表均显示灯箱编号与最近亮灯证据（信号时间、
  亮灯百分比、文字结论）；地图圆点外环为广告画面预览色。
- **灯箱详情**：登记信息、合同版本、巡检照片（本地 PNG，纯标准库生成）与历史。
- **故障详情**：时间条与表格把**计划亮灯时段与实际黑屏逐轮对照**，并给按合同
  版本的补播明细与审批入口。
- **维修派单 / 工单**：派单、填报修复、现场复验（通过关闭 / 不达标重开）。
- 配色：白 `#FFFFFF`、墨灰 `#2A2D34`，状态以画面预览色点缀；每种颜色状态都
  同时给出文字结论。

## 技术形态

- Python 3 标准库（`sqlite3` / `http.server` / `zlib` 写 PNG），无第三方依赖。
- SQLite 存时段、合同、信号、巡检、故障、黑屏轮次、工单与补播结论；照片存本地
  `data/photos/`；亮灯信号走模拟适配器 `lightbox/signal_.py`（`auto/on/off/half`
  + 回路中断状态），预留替换为真实电流/控制器适配器的位置。

## 测试

```bash
python3 -m unittest discover -s tests      # 30 项，全部通过
```

覆盖：时段判断（含跨午夜、白天排除）、六类情形分类、回路/同箱/relapse 归并、
禁止平行工单、补播按合同版本分摊与半亮折算、复验与补播审批权限，以及 HTTP
端到端页面与 POST 规则。

## 代码结构

```
lightbox/
  db.py        SQLite schema（含未关闭工单唯一索引）
  clock.py     可注入虚拟时钟
  schedule.py  计划窗口/跨午夜/黑屏与计划重叠分钟
  signal_.py   模拟亮灯信号适配器
  photos.py    本地巡检照片 PNG 生成
  engine.py    分类、归并、派单、修复、复验
  makeup.py    补播按版本分摊与结论审批
  seed.py      半亮样例预置
  web.py / run.py  HTTP 界面与一键启动
tests/         单元 + HTTP 端到端测试
```
